# Spec: Introduction section

## Goal

Create the first page of Judah's personal website as a small static HTML page that introduces him to recruiters and fellow engineers, while remaining approachable to general readers.

## Scope

- Put the approved introduction in the repository root as `index.html`.
- Use native semantic HTML only in this step.
- Do not add a framework, dependencies, styling, JavaScript, hosting, or unrelated sections.

## Approved copy

> Hi, I’m Judah. I’m a backend engineer with experience in Go and Java. I’ve been part of teams working on lending, customer care, and post-order experiences. I’m always open to learning and improving my skills.

## Acceptance criteria

- The document declares English, UTF-8, and a responsive viewport.
- The introduction is inside the page's main content and a labeled section with one top-level heading.
- The page title identifies Judah as a backend engineer.
